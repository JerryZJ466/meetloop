### 需要守住的重点

**第一，UIKit 必须进入首个 iOS 面试门槛。**SwiftUI 是好的起点，但国内移动实习样本仍明确要求 UIKit、生命周期和布局。应在 M0—M3 内完成列表复用、导航、退出取消，并安排一个简短的 Objective-C 阅读/Swift 互操作实验；无需另开完整 ObjC 主课。

**第二，Web 基础应有交付物。**React 的组件和状态思维可以迁移，RN 的布局与原生组件不能代替浏览器 DOM、CSS 和 Web 安全。A4 用 AgentDesk 自己的业务、后端和数据完成控制台；两个项目保持代码、数据库和部署独立，只共享学习过的知识。若目标转向纯 Web 前端，再启动额外 **80—140h** 的 Web 深度分支，补组件设计、浏览器渲染/缓存、性能及兼容性；该分支不算 MeetLoop 默认主线已完成。

**第三，项目不能代替基础与独立实现。**公共训练固定每周 3h，计入总周预算，两个项目不重复记账。数学不强不妨碍学习必要的数据结构、算法与系统知识。每阶段需要关闭整段 AI 生成，独立完成变更、定位故障并说明验证方法；会运行 AI 给出的代码不足以通过验收。

**第四，后端可以小，正确性不能省。**保留认证、资源权限、输入校验、数据库约束/迁移、报名事务、幂等与日志。通用 SDE 需要理解一次操作如何贯通客户端、API 和数据库，并能说明失败时的行为；不要求此时构建分布式平台。

### 暂不扩张的内容

Android 保持宿主、生命周期、协程与一个原生能力；不复制整个 iOS 产品。Flutter、Lynx、KMP、Electron、GraphQL、RxSwift、鸿蒙等按明确目标 JD 选择后续实验。微服务、Kafka、Kubernetes、DDD、海量并发与完整框架源码不是开工条件。社招样本展示的是长期发展空间，不能把所有要求叠成新人的必修清单。

学习入口可使用 [MDN Core](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core)、[React Learn](https://react.dev/learn) 与 [RN 官方宿主集成](https://reactnative.dev/docs/integration-with-existing-apps)。这些入口本次已可读取；具体工具版本在进入对应阶段时重新核对，工程配置与依赖须匹配同一版本。

审核结论：按阶段做完并通过验收，可以建立面向移动端/跨端实习与初级工程岗位的作品证据；结合 A4 和公共基础，也能支撑部分产品型全栈岗位的准备。不能据此宣称精通全部大前端、覆盖所有 SDE 岗位，或保证未来招聘结果。
