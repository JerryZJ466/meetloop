# MeetLoop 从这里开始

## 第一周

1. 继续 100 Days of SwiftUI 当前章节；已经能独立完成的内容不重刷。
2. 用变量、集合和函数保存与筛选活动；课程每学一项，就改一个条件独立练习。
3. Mac 可用时建立 SwiftUI 工程与首次提交；未到货时先用纯 Swift 练习。
4. 记录自己不能解释的代码；每周至少一次不依赖 AI 整段生成。

## 后三周

- 第 2 周：列表、详情、导航、内存报名 / 取消与状态来源。
- 第 3 周：我的报名、四态、Mock Repository、空结果和错误开关。
- 第 4 周：按基础加入并发 / 取消、关键测试和首次用户反馈。

若语言与状态尚不熟练，延长当前阶段。RN 和 Kotlin 等 iOS 基础关卡通过后再启动。

## 每周复盘

- 我能独立改什么？
- 复现了什么故障，原因是什么？
- 什么证据证明修复有效？
- 下周只推进哪一个主要问题？
