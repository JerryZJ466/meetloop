# MeetLoop 从这里开始

当前主计划：v3.1（2026-10-29）。只按 [当前主计划](plans/plan.md) 的M0-M5、M7核心推进；M6/MG选修；旧PDF保留作历史。你的Mac、Xcode和实际语言水平尚未验证，先做M0。

## 今天约3小时

1. **45分钟基线**：不用AI整段代写，定义活动（id、标题、容量、已报名人数），写筛选和“是否可报名”；列空列表、满员和重复ID的处理。不懂的地方记录下来。
2. **45分钟补课**：100 Days of SwiftUI对应语言章节；完成一道改条件练习。已掌握的内容不重刷。
3. **60分钟实践**：Mac可用就建SwiftUI工程，显示三条活动并Git提交；还没就绪就先做纯Swift数据练习和Git，UI验收延后。
4. **30分钟验证**：看diff、运行断言/应用，写200字解释状态放哪里、哪里不会。记录到PROGRESS，未达到M0标准不要打完成勾。

## 第一周13小时示例

环境/基线3h、课程和练习3h、模型与列表5h、测试/复盘2h。M0预计10-15h，若未通过，本周剩余时间继续M0；不是第一周一定做完应用。

## 前四周约52小时

| 周 | 重点 | 期望证据 |
| --- | --- | --- |
| 1 | M0，工具链与Swift基础 | 活动模型/筛选、可构建工程、首次提交 |
| 2 | M0过关后M1列表/详情 | 能独立改字段，解释导航和状态所有者 |
| 3 | M1内存报名/取消 | 容量、重复点击和取消的断言 |
| 4 | M1我的报名、四态和第一次小演示 | 单一状态源、独立规则变更；未完成就顺延 |

M0+M1预计55-80h，所以前四周可能只完成M1的大部分，这是正常进度。M2网络/并发与M3 UIKit与首轮作品等当前关卡通过后再开始；RN在M4之后，Android深化在M6选修，Go在MG选修。Today和Stanford不与100 Days整套同时开课。

## 开工核对（需要你实际执行）

- [ ] Git可用，远程指向自己的meetloop，先拉取最新main。
- [ ] Mac/Xcode可用，创建并运行最小工程，记录版本和目标系统。
- [ ] 独立完成基线练习，按结果决定补哪一节课。
- [ ] 知道凭据/运行数据不提交；依赖锁文件需要提交。
- [ ] 建立每周13h项目与3h公共训练安排。

Mac未到或安装受限不影响阅读和纯Swift练习，但不能据此认定iOS环境已准备好。
